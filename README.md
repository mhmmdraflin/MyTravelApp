# ✈️✨ My Travel – Aplikasi Perjalanan & Wisata

**My Travel** adalah aplikasi mobile berbasis Flutter yang dirancang untuk memudahkan pengguna dalam merencanakan perjalanan dan menjelajahi destinasi wisata impian mereka.

> 📘 **Catatan:** Proyek ini merupakan aplikasi yang dikembangkan untuk mempermudah eksplorasi tempat wisata dengan antarmuka yang modern dan interaktif.

## 🚀 Cara Menjalankan Proyek

1. **Clone Repositori:**

   ```bash
   git clone https://github.com/mhmmdraflin/MyTravelApp.git
   ```

2. Buka folder proyek menggunakan **Visual Studio Code** atau **Android Studio**.
3. Jalankan perintah untuk mengunduh dependensi:
   ```bash
   flutter pub get
   ```
4. Tekan tombol **Run** atau jalankan perintah berikut di terminal:
   ```bash
   flutter run
   ```

> ⚠️ **Penting:** Pastikan Anda telah mengonfigurasi Emulator Android atau iOS Simulator sebelum menjalankan aplikasi.
